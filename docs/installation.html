Installation Guide

Install Orbit on any Linux server in under a minute. Default port: 5000. All ports must be in range 5000–6000.

Requirements

  • Linux (Ubuntu 20.04+, Debian 11+, CentOS 8+, AlmaLinux, Rocky, Fedora, Arch)
  • x86_64, arm64, or armv7 architecture
  • systemd
  • curl, openssl, tar (installer auto-installs if missing)
  • Root / sudo access

Method 1 — One-liner (recommended)

bash
curl -fsSL https://raw.githubusercontent.com/KenyanRedwoods01/Orbit/main/scripts/install.sh | sudo bash

Method 2 — Clone and run

bash
git clone https://github.com/KenyanRedwoods01/Orbit.git
cd Orbit
sudo bash scripts/install.sh

Method 3 — Docker (builds from source)

No pre-built Docker image is published yet. Docker Compose builds the image locally from source.

bash
git clone https://github.com/KenyanRedwoods01/Orbit.git
cd Orbit
cp .env.example .env          # set ORBIT_SECRET_KEY
docker compose up -d          # builds image then starts on port 5000

Or build and run manually:

bash
docker build -t orbit .
docker run -d \
  --name orbit \
  --cap-add NET_ADMIN --cap-add SYS_PTRACE \
  -p 5000:5000 \
  -v orbit-data:/var/lib/orbit \
  orbit

Installer options

bash
sudo bash install.sh --port 5100 --version v1.2.0 --no-start
  • --port — Panel port (5000–6000, default 5000)
  • --mcp-port — MCP TCP port (5000–6000, default 5001)
  • --metrics-port — Prometheus metrics port (default 5002)
  • --version — Specific release tag (default: latest)
  • --no-start — Skip starting the service after install
  • --uninstall — Remove Orbit (preserves data directory)

After installation

Open https://YOUR_SERVER_IP:5000 in your browser. A setup wizard will guide you through creating your admin account.

Self-signed certificate: Your browser will show a security warning on first visit. This is expected — Orbit generates a self-signed TLS certificate on first run. Proceed past the warning, or configure your own certificate in /etc/orbit/orbit.toml.

Service management

bash
systemctl status orbit       # check status
systemctl restart orbit      # restart after config change
journalctl -u orbit -f       # follow logs
systemctl stop orbit         # stop

Uninstall

bash
sudo bash scripts/install.sh --uninstall
# Data at /var/lib/orbit is preserved. Remove manually if desired.
