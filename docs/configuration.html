Configuration Reference

Orbit reads /etc/orbit/orbit.toml on startup. All fields are optional — Orbit uses safe defaults when the file is absent.

Top-level keys

KeyDefaultDescription
listen_addr0.0.0.0:5000Host:port for the main HTTPS panel. Port must be 5000–6000.
data_dir/var/lib/orbitSQLite database and BoltDB metric ring storage directory.
tls_cert_file(auto)PEM certificate path. Leave empty for auto self-signed.
tls_key_file(auto)PEM private key path. Leave empty for auto self-signed.
secret_key(auto)JWT signing secret. Auto-generated on first run if empty.

[modules] section

Set any module to false to disable it entirely. All are true by default.

KeyDescription
metricsReal-time CPU/memory/disk/network charts
servicesSystemd service manager
logsLive log viewer (journald + file)
firewallnftables/iptables management
web_serverNginx/Apache vhost manager
deployGitOps pipeline engine
databaseDatabase connection manager
uptimeHTTP/TCP uptime monitors
securityWazuh/Suricata/CrowdSec/Fail2ban
multi_serverRemote SSH server fleet
containersDocker container management

[mcp] section

KeyDefaultDescription
enabledfalseEnable the MCP server
socket_path/run/orbit/mcp.sockUnix socket path for local MCP connections
tcp_addr(disabled)Optional TCP listener, e.g. 127.0.0.1:5001 (port 5000–6000)

[[server]] blocks

Add one block per remote server you want to manage from this Orbit instance.

orbit.toml
[[server]]
name     = "web-01"
host     = "192.168.1.10"
user     = "ubuntu"
key_file = "/home/orbit/.ssh/id_ed25519"

[[server]]
name     = "db-01"
host     = "10.0.0.5"
user     = "orbit"
key_file = "/home/orbit/.ssh/id_ed25519"

Complete example

/etc/orbit/orbit.toml
listen_addr = "0.0.0.0:5000"
data_dir    = "/var/lib/orbit"
secret_key  = "your-secret-here"

[modules]
metrics      = true
services     = true
logs         = true
firewall     = true
web_server   = true
deploy       = true
database     = true
uptime       = true
security     = true
multi_server = true
containers   = true

[mcp]
enabled     = false
socket_path = "/run/orbit/mcp.sock"
# tcp_addr = "127.0.0.1:5001"
