MCP Integration

Orbit ships a built-in Model Context Protocol (MCP) server, letting AI assistants like Claude interact with your server through a secure, structured interface.

Enable MCP

/etc/orbit/orbit.toml
[mcp]
enabled     = true
socket_path = "/run/orbit/mcp.sock"

# Optional: expose MCP over TCP for remote AI agents
# Port must be in range 5000-6000
tcp_addr    = "127.0.0.1:5001"

Restart Orbit after changing MCP settings: systemctl restart orbit

Connect Claude Desktop (Unix socket)

claude_desktop_config.json
{
  "mcpServers": {
    "orbit": {
      "command": "socat",
      "args": ["STDIO", "UNIX-CONNECT:/run/orbit/mcp.sock"]
    }
  }
}

Connect via TCP (remote agent)

claude_desktop_config.json
{
  "mcpServers": {
    "orbit-remote": {
      "command": "socat",
      "args": ["STDIO", "TCP:your-server-ip:5001"]
    }
  }
}
Security: When exposing MCP over TCP, bind to 127.0.0.1 and use an SSH tunnel for remote access. Never expose port 5001 directly to the internet without additional authentication.

Available MCP tools

  • get_metrics — CPU, memory, disk, and network statistics
  • list_services — Running systemd services and their status
  • list_containers — Docker containers
  • get_logs — Recent journal or file log entries
  • list_processes — Running processes with resource usage
  • list_ports — Open network ports
  • firewall_rules — Active firewall rules (read-only)
