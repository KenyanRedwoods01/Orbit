Contributing to Orbit

Contributions are welcome! Here's how to get your development environment running and submit a pull request.

Prerequisites

  • Go 1.22+
  • Node.js 20+ and npm
  • gcc (for CGO / sqlite3)
  • golangci-lint (optional, for linting)

Local development setup

bash 
git clone https://github.com/KenyanRedwoods01/Orbit.git
cd Orbit

# Install frontend dependencies and build
cd web && npm install && npm run build && cd ..

# Build binary (embeds frontend)
make build

# Run with the example config (port 5000)
./dist/orbit --config orbit.example.toml

Development workflow

bash — make targets 
make test        # run Go tests with race detection
make lint        # run golangci-lint
make web-dev     # Vite dev server (hot reload for frontend)
make run         # run Go backend with orbit.example.toml

Submitting a pull request

  1. Fork the repository on GitHub
  2. Create a feature branch: git checkout -b feat/my-feature
  3. Make your changes and add tests where applicable
  4. Run make test lint — all checks must pass
  5. Commit with a conventional commit message
  6. Push and open a pull request against main

Commit message format

  • feat: new feature
  • fix: bug fix
  • docs: documentation only
  • chore: maintenance, build, or tooling changes
  • test: adding or updating tests
  • refactor: code restructuring (no feature change)

Project structure

tree
Orbit/
├── cmd/orbit/          # main entry point
├── internal/
│   ├── api/            # HTTP handlers (one file per feature)
│   ├── auth/           # JWT authentication + TOTP
│   ├── collector/      # system metrics collector (/proc)
│   ├── config/         # TOML config loader + defaults
│   ├── db/             # SQLite + BoltDB init and schema
│   ├── mcp/            # MCP server
│   └── modules/        # one package per feature module
├── web/                # React + Vite frontend
│   └── src/
│       ├── components/ # shared UI components
│       ├── hooks/      # custom React hooks
│       ├── lib/        # API client
│       ├── pages/      # one directory per module
│       └── types/      # shared TypeScript types
├── scripts/            # install.sh
├── packaging/          # GoReleaser Dockerfile, systemd unit
├── deploy/             # Nginx config
├── Dockerfile          # multi-stage build from source
├── docker-compose.yml  # Docker Compose (builds from source)
├── docs/               # GitHub Pages site
└── .github/workflows/  # ci.yml, release.yml, pages.yml, security.yml
