API Reference

Orbit exposes a REST API at /api/v1 and WebSocket streams at /ws. The full OpenAPI spec is served at https://your-server:5000/api/openapi.json.

Authentication

All endpoints require a JWT in the Authorization: Bearer <token> header. Obtain a token by posting credentials to /api/v1/auth/login.

Tip: Import the OpenAPI spec at /api/openapi.json directly into Postman or Insomnia for a complete interactive client.

System info

GET/api/v1/sysinfoHost OS, kernel, uptime
GET/api/v1/metricsCurrent CPU / memory / disk snapshot
GET/ws/metrics WebSocket live metric stream

Processes

GET/api/v1/processesList running processes
DEL/api/v1/processes/{pid}Kill a process

Services (systemd)

GET/api/v1/servicesList systemd units
POST/api/v1/services/{name}/startStart a service
POST/api/v1/services/{name}/stopStop a service
POST/api/v1/services/{name}/restartRestart a service

Containers (Docker)

GET/api/v1/containersList all containers
POST/api/v1/containersCreate a container
POST/api/v1/containers/{id}/startStart container
POST/api/v1/containers/{id}/stopStop container
DEL/api/v1/containers/{id}Remove container
GET/ws/containers/{id}/logs WebSocket live container logs

Firewall

GET/api/v1/firewall/rulesList firewall rules
POST/api/v1/firewall/rulesAdd a rule
DEL/api/v1/firewall/rules/{id}Remove a rule

Deployments

GET/api/v1/pipelinesList pipelines
POST/api/v1/pipelines/{id}/triggerTrigger a deployment
GET/ws/deploy/{id}/logs WebSocket live deploy logs

Full OpenAPI spec

The machine-readable OpenAPI 3.0 specification is served at runtime:

GET https://your-server:5000/api/openapi.json
